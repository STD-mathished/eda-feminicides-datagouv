## Contexte du projet

Ce projet d'analyse de données (Exploratory Data Analysis - EDA) est réalisé et publié à l'occasion du mois de novembre, en soutien à la **Journée internationale pour l'élimination de la violence à l'égard des femmes (25 novembre)**.

L'objectif de ce dépôt est d'utiliser la Data Science et l'ingénierie de la donnée pour analyser de manière factuelle les dynamiques de ces drames en France, en s'appuyant sur des données gouvernementales ouvertes.


## Source des données

Les données utilisées dans ce projet proviennent de la plateforme **data.gouv.fr**. 
* **Lien des dataset :** 
* [Décompte et recensement des féminicides](https://www.data.gouv.fr/datasets/decompte-et-recensement-des-feminicides) - données d'août 2026


* [Cartographie des cellules de lutte contre les violences sexistes et sexuelles] (https://www.data.gouv.fr/datasets/cartographie-des-cellules-de-lutte-contre-les-violences-sexistes-et-sexuelles) - données du 24 février 2026

## Stack Technique

* **Langage :** Python 3
* **Nettoyage et manipulation de données :** `pandas`, `numpy`
* **Data Visualisation :** `matplotlib`, `seaborn`
* **Environnement :** Jupyter Notebook (`.ipynb`)

## Utilisation et installation

Pour exécuter ce projet sur votre machine locale :

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/VOTRE_NOM_UTILISATEUR/analyse-feminicides-france.git
   ```
2. Accédez au dossier :
   ```bash
   cd analyse-feminicides-france
   ```
3. Installez les dépendances requises :
   ```bash
   pip install -r requirements.txt
   ```
4. Lancez Jupyter Notebook :
   ```bash
   jupyter notebook
   ```
